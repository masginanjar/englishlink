# DESIGN.md — Englishlink Translator

Arah: cerah, ramah, gaya platform edukasi modern (referensi suasana: englishvit.com). Putih bersih, biru terang sebagai warna utama, kuning amber untuk ajakan, panel hero berwarna penuh. Logo, ilustrasi, dan teks tetap milik Englishlink sendiri.

## Warna
| Token | Nilai | Dipakai untuk |
|---|---|---|
| --bg | #ffffff | Latar halaman |
| --soft | #f4f7ff | Section selang-seling, hero halaman dalam |
| --ink | #0d1b3d | Teks utama |
| --muted | #55607a | Teks pendukung |
| --blue | #1b5cff | Tombol utama, link, kata yang disorot di judul |
| --navy | #0b1f4b | Footer, section formulir |
| --amber | #ffb81f | Tombol ajakan di atas biru, aksen |
| --coral | #d83a47 | Slide hero ketiga, cap |
| --green | #1faa59 | Ikon dan tombol WhatsApp |

## Tipografi
Plus Jakarta Sans. Judul 800, isi 400–600, line-height 1.65. Judul section rata tengah, satu frasa disorot biru (tulis `*frasa*` di data).

## Bentuk
- Radius: 28px (hero), 20–24px (kartu, banner), 16px (tombol), 14px (input).
- Bayangan lembut hanya saat hover dan pada elemen mengambang.
- Kartu layanan: kotak ikon berwarna di atas, judul, deskripsi, link "Lihat selengkapnya".
- Target sentuh minimal 44px. Tombol WhatsApp hijau mengambang hanya di layar kecil.

## Aturan
- Satu H1 per halaman (slide pertama hero). Slide lain memakai paragraf bergaya judul.
- Tidak menampilkan harga, ulasan, logo instansi, atau angka yang belum dikonfirmasi pemilik.
- Belum ada foto. Kalau nanti ditambah, pakai foto milik sendiri atau berlisensi, simpan di folder situs.
